## Changelog (v1.0.5)

### Fixed
* **Network lag on integrated servers:** Removed the forced 500 Mbps bandwidth limit for non-dedicated servers, which was previously overflowing the player's network channel and causing timeout disconnects.
* **Improved multi-threaded model sync:** Increased the `SYNC_EXECUTOR` thread pool size from 2 to 32, eliminating network stack bottlenecks when multiple players log in simultaneously.
* **Server Sync Exception (`IndexOutOfBoundsException`) & Desync Kicks:** Fixed a severe race condition in `nativeSyncModels` and flawed timeout logic that corrupted the encryption keys between the client and server during model handshakes. This caused packets to be decrypted into garbage data, spamming the server console with `IndexOutOfBoundsException: readerIndex(2) + length(98) exceeds writerIndex(67)` and permanently breaking model synchronization for the session, eventually kicking players with `java.net.SocketException: connection reset`. Packets are now robustly verified by type, the race condition is resolved, and the garbage-header parser is safe against bounds errors.
* **Memory Leak on Reconnect:** Fixed a critical memory leak where the client network connection object (`Connection`) was not cleared upon disconnection. This held references to the entire previous world (`ClientLevel`), player (`LocalPlayer`), and all loaded chunks/entities, leading to `OutOfMemory` crashes when repeatedly joining singleplayer worlds or servers.
* **Memory Leak on Log Out:** Added proper cleanup of model upload states (`uploadStates`) when a player disconnects during synchronization, preventing resource retention on the server.
* **Non-functioning Cache Trimming & TTL:** Rewrote the `trimUnusedGpuCaches()` method. Inactive models are now properly unloaded from VRAM/RAM after their Time-To-Live (TTL) expires, even if the maximum model cache size (`MaxCachedGpuModels`) is set to `0` (disabled). Also fixed a bug where viewing models in the GUI menu did not update their last-used timestamp, which previously prevented them from ever being cleared.
* **Case-Preserving Path Warning:** Fixed errors and warnings when importing models on Windows, where case-sensitive folder lookups caused load ID mismatches (due to paths being normalized to lowercase). Path checks are now correctly case-insensitive.
